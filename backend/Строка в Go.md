## Строки в Go: подробный ответ

### **17 грейд (базовый уровень)**

**Строка в Go — это read-only срез (slice) байтов** [[12]]. 

**Внутренняя структура:**
Строка представлена в памяти как структура из двух слов (2-word structure) [[8]]:
```go
type stringStruct struct {
    str  unsafe.Pointer  // указатель на данные (байты)
    len  int             // длина строки в байтах
}
```

**Ключевые свойства:**
- **Неизменяемость (immutability)** — байты строки нельзя изменить после создания [[2]]
- **UTF-8** — строки в Go по конвенции содержат UTF-8 закодированный текст [[19]]
- **Read-only** — при попытке изменить строку произойдет ошибка компиляции

**Пример:**
```go
s := "hello"
// s[0] = 'H'  // ОШИБКА: cannot assign to s[0]
```

### **18 грейд (продвинутый уровень)**

#### **1. Итерация по строке (runes)**

В Go есть **два способа** итерации по строке:

**Способ 1: По байтам (неправильно для Unicode)**
```go
s := "привет"
for i := 0; i < len(s); i++ {
    fmt.Printf("%c ", s[i])  // Выведет отдельные байты, не символы!
}
```

**Проблема:** `s[i]` имеет тип `byte` (uint8) и возвращает отдельный байт, а не символ [[17]]. Для кириллицы и других Unicode символов это даст некорректный результат.

**Способ 2: По рунам (правильно)**
```go
s := "привет"
for i, r := range s {
    fmt.Printf("Индекс %d: руна %c\n", i, r)
}
```

**Как работает `range` по строке:**
- Специально обрабатывает строки как UTF-8 [[18]]
- Автоматически декодирует UTF-8 последовательности в руны
- Возвращает **индекс в байтах** и **руну** (Unicode code point) [[22]]

---

#### **2. Подсчет количества рун в строке**

**Проблема:** `len(s)` возвращает **количество байт**, а не символов [[29]].

```go
s := "привет"
fmt.Println(len(s))  // 12 байт (каждая кириллическая буква = 2 байта в UTF-8)

// Правильный подсчет рун:
fmt.Println(utf8.RuneCountInString(s))  // 6 рун
// ИЛИ:
fmt.Println(len([]rune(s)))  // 6 рун
```

### **Разница между byte и rune**

| Характеристика | **byte** | **rune** |
|----------------|----------|----------|
| **Тип** | `uint8` (алиас) | `int32` (алиас) [[15]] |
| **Размер** | 1 байт (8 бит) | 4 байта (32 бита) |
| **Назначение** | Хранение сырых байтов | Unicode code point [[14]] |
| **Диапазон** | 0-255 | 0-0x10FFFF (все Unicode символы) |

**Пример:**
```go
s := "A"      // ASCII символ
fmt.Println(len(s))           // 1 байт
fmt.Println(len([]rune(s)))   // 1 руна

s2 := "α"     // Греческая буква (Unicode)
fmt.Println(len(s2))          // 2 байта (UTF-8 кодировка)
fmt.Println(len([]rune(s2)))  // 1 руна

s3 := "🙂"    // Emoji
fmt.Println(len(s3))          // 4 байта
fmt.Println(len([]rune(s3)))  // 1 руна
```

### **UTF-8 кодировка в Go**

**Важные факты:**
1. **Исходный код Go всегда UTF-8** [[19]]
2. **Строка хранит произвольные байты**, но строковые литералы содержат валидный UTF-8 [[10]]
3. **UTF-8 переменная длина**: 
   - ASCII (0-127): 1 байт
   - Кириллица, греческий: 2 байта
   - Большинство азиатских символов: 3 байта
   - Emoji, редкие символы: 4 байта

**Пример с разными символами:**
```go
s := "Hello Привет 世界 "

// По байтам (неправильно):
for i := 0; i < len(s); i++ {
    fmt.Print(s[i])  // Выведет мусор для не-ASCII
}

// По рунам (правильно):
for i, r := range s {
    fmt.Printf("%d: %c\n", i, r)
}
// Вывод:
// 0: H
// 1: e
// 2: l
// 3: l
// 4: o
// 5:  
// 6: П
// 7: р
// ... и т.д.
```

### **Практические рекомендации**

**1. Всегда используйте `range` для итерации по строкам:**
```go
// ✅ Правильно:
for _, r := range s {
    // работа с руной r
}

// ❌ Неправильно (для Unicode):
for i := 0; i < len(s); i++ {
    // работа с байтом s[i]
}
```

**2. Для подсчета символов используйте `utf8.RuneCountInString`:**
```go
import "unicode/utf8"

count := utf8.RuneCountInString(s)  // Эффективно
// ИЛИ:
count := len([]rune(s))  // Менее эффективно (создает срез)
```

**3. Для доступа к отдельным символам конвертируйте в []rune:**
```go
runes := []rune(s)
firstRune := runes[0]  // Первая руна
```

**4. Помните о неизменности строк:**
```go
// Нельзя изменить строку:
// s[0] = 'A'  // ОШИБКА

// Создайте новую:
s = "A" + s[1:]
```

---

### **Итог**

1. **Строка в Go** — неизменяемый срез байтов с UTF-8 кодировкой [[12]]
2. **Byte** — отдельный байт (uint8), **rune** — Unicode code point (int32) [[15]]
3. **`len(s)`** — количество байт, **`len([]rune(s))`** — количество символов
4. **`range`** по строке автоматически декодирует UTF-8 в руны [[18]]
5. Для работы с Unicode всегда используйте руны, не байты!
